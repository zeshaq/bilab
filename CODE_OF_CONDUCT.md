# Code of Conduct

bilab is a small, focused project. We keep it that way by being direct,
technical, and respectful.

- Be kind and assume good faith.
- Critique ideas and code, never people.
- Keep discussions focused on the work.
- Respect confidentiality: this is a private repository.

Unacceptable behavior includes harassment, hate speech, personal attacks,
and leaking private information. Maintainers will remove contributions or
contributors that violate these rules.

If you're working on bilab, you're expected to follow the engineering
principles in `docs/development/principles.md` and this code of conduct.
